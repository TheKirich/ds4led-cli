ds4led-cli — управление цветом lightbar DualShock 4 на Linux
=========================================================

Лёгкая утилита (один bash-файл, ~2 МБ памяти службы, ноль зависимостей)
для управления светодиодной полоской геймпада DualShock 4 (PS4) на Linux.
Умеет устанавливать цвет, «запоминать» его и восстанавливать после
переподключения контроллера через службу systemd.

Возможности
-----------
* Установка любого цвета полоски: hex, RGB-триплет или случайный цвет
* Поддержка подключения по USB и по Bluetooth
* Несколько контроллеров: цвет всем или выбранному по индексу
* Просмотр списка контроллеров и их текущего цвета
* Автовосстановление цвета после переподключения (режим --watch)
* Цвет и интервал опроса задаются в конфиге /etc/ds4led-cli.conf
* Горячая перезагрузка конфига без перезапуска службы
* Ручной цвет обновляет конфиг — «как поставил, так и останется»
* Установка и удаление системной службы одной командой (ds4led-cli install /
  ds4led-cli uninstall) — файл-установщик не нужен, всё внутри одного скрипта
* Репетиция без записи на устройство: --dry-run
* Никаких udev-правил: утилита пишет в LED только под root (sudo),
  а служба работает от root сама

Как это работает
----------------
Ядро Linux (>= 5.15, драйвер hid_playstation) экспортирует цвет полоски
DS4 через sysfs как три LED-канала + переключатель яркости:

  /sys/class/leds/<dev>:red/brightness     0–255
  /sys/class/leds/<dev>:green/brightness   0–255
  /sys/class/leds/<dev>:blue/brightness    0–255
  /sys/class/leds/<dev>:global/brightness  0/1 — вкл/выкл

где <dev> — каталог устройства вида 0003:054C:05C4.* (USB) или
0005:054C:09CC.* (Bluetooth). Префикс имён LED (inputN) динамический,
поэтому поиск ведётся по пути устройства.

Установка
---------
Требования: Linux с ядром >= 5.15, bash, systemd, coreutils.

  # установить как системную службу (включая автозапуск)
  sudo ./ds4led-cli install

  # проверить статус службы
  systemctl status ds4led-cli

  # задать свой цвет по умолчанию (опционально)
  sudo nano /etc/ds4led-cli.conf

Повторный запуск обновляет копию скрипта и юнит,
не трогая существующий конфиг.

Использование
-------------
  ds4led-cli <цвет> [индекс|all]   установить цвет (по умолчанию всем)
  ds4led-cli random [индекс|all]   случайный заметный цвет
  ds4led-cli list                  список контроллеров: индекс, путь, цвет
  ds4led-cli --watch [сек]         поддерживать цвет (демон, по умолчанию 3с)
  ds4led-cli --dry-run <цвет>      показать, что будет записано, не писать
  ds4led-cli install               установить службу systemd (sudo)
  ds4led-cli uninstall             удалить службу и копию (sudo)
  ds4led-cli --help | --version

Форматы цвета
-------------
  aabbcc        hex без префикса
  #aabbcc       hex с решёткой (в shell берите в кавычки)
  0xaabbcc      hex с префиксом 0x
  255 0 0       RGB-триплет (три числа 0–255)
  random        случайный заметный цвет (хотя бы один канал >= 64)

Примеры
-------
  sudo ds4led-cli ff0000          красный, всем контроллерам
  sudo ds4led-cli '#00ff88' 1     бирюзовый, только контроллер №1
  sudo ds4led-cli 0 0 255         синий
  sudo ds4led-cli random          случайный цвет
  ds4led-cli list                 посмотреть, что найдено
  ds4led-cli --dry-run ff8800     репетиция без записи

Конфигурация
------------
/etc/ds4led-cli.conf — плоский формат «ключ=значение», поддерживаются
комментарии (#) и пробелы вокруг «=»:

  # Цвет полоски по умолчанию (hex rrggbb)
  color=ff0000
  # Интервал опроса в режиме --watch, секунды
  interval=3

* Ручная установка цвета (sudo ds4led-cli <цвет>) обновляет значение color
  в конфиге.
* После установки права на файл 666 — читать и редактировать может
  любой пользователь без sudo; права сохраняются и при ручных
  обновлениях цвета из-под root.
* Служба перечитывает конфиг автоматически (по времени изменения файла):
  поменяйте цвет или interval — применится без перезапуска.
* Если конфига нет, режим --watch использует последний ручной цвет
  (хранится в /root/.local/state/ds4led-cli/last_color).
* Альтернативный путь конфига: флаг --config <файл> или переменная
  окружения DS4LED_CONFIG.

Удаление
--------
  sudo ds4led-cli uninstall

Удаляет службу и /usr/local/bin/ds4led-cli. Конфиг и состояние не удаляются
(пути выводятся), чтобы при повторной установке цвет сохранился.
Полная очистка: удалить /etc/ds4led-cli.conf и /root/.local/state/ds4led-cli/.

Коды выхода
-----------
  0   успех
  1   неверные аргументы / нет конфига для --watch
  2   контроллер не найден
  3   нет прав root
  4   ошибка записи в LED

Известные ограничения
---------------------
* Поддерживается только DualShock 4 (VID 054C, PID 05C4/09CC).
  DualSense и другие геймпады не определяются.
* Требуется hid_playstation (ядро >= 5.15); с устаревшим hid_sony
  утилита сообщит об этом.
* Запись в LED возможна только от root: интерактивно — через sudo,
  автоматически — через системную службу.

Диагностика
-----------
Если контроллер не найден (код выхода 2), утилита подскажет вероятную
причину: не подключён, устаревший драйвер hid_sony, отсутствие модуля
hid_playstation. Также проверьте:

  ls /sys/class/leds/ | grep -i 054C     # есть ли LED от геймпада
  lsmod | grep playstation               # загружен ли драйвер
